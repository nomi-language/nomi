Some code is better written by a program than by hand: an enum for every
value a data file lists, a lookup function for every row of a table, a typed
function for every SQL query. Nomi has no macros. A library that writes code
for you ships a **tool**, an ordinary Nomi program that reads your data and
writes ordinary `.nomi` files. You run it, read what it wrote, and commit
it, like any other file of your project.

The [Databases](/databases/) chapter uses the biggest example, sqlkit's
`nomi tool sqlkit generate`, which turns SQL queries into typed functions.
This chapter writes two small generators of its own.

## A tool

A cafe lists the choices it offers in a file, one line per enum:

```text
Size: small medium large
Roast: light medium dark
```

A tool turns each line into an enum. A tool is a program in a module's
`tools/` directory, here the module `choices`, kept beside the project
under `generators/choices/`:

```tree
cafe/
├── go.mod
├── nomi.toml
├── enums.choices
├── enums.nomi
├── main.nomi
└── generators/choices/
    ├── go.mod
    ├── nomi.toml
    └── tools/generate.nomi
```

The module lists the tool among its entry points, and the cafe adds the
module as it adds any dependency:

```console
$ nomi add ./generators/choices
added choices from ./generators/choices (module choices)
```

`nomi tool choices generate` runs `tools/generate.nomi` of the module
`choices`, in the current directory, with every effect a program has. It
reads `enums.choices` and writes `enums.nomi`, which `main.nomi` imports
like any other file. This example runs the tool before each run, as you
would after an edit. Add a size, or a line of your own, and run it again:
the generated file's tab shows the change.

```nomi-run manual tool:choices/generate
// FILE: enums.choices
Size: small medium large
Roast: light medium dark

// FILE: main.nomi
import {
    std/io
    enums.{Roast, Size}
}

fn ounces(size: Size) -> Int {
    case size {
        Size.Small -> 8
        Size.Medium -> 12
        Size.Large -> 16
    }
}

fn main() {
    io.print(ounces(Size.Medium))
    io.print(Roast.Dark == Roast.Dark)
}

// FILE: enums.nomi
// Generated by `nomi tool choices generate` from enums.choices. Do not edit.
/// The choices of `Size` in enums.choices.
pub enum Size {
    Small
    Medium
    Large
}

/// The choices of `Roast` in enums.choices.
pub enum Roast {
    Light
    Medium
    Dark
}

// FILE: generators/choices/tools/generate.nomi
// `nomi tool choices generate`: write enums.nomi from enums.choices, one
// enum per line. A line `Size: small medium large` declares
// `pub enum Size` with the variants `Small`, `Medium` and `Large`.
import {
    std/fs
    std/io
}

fn main() -> Result<Unit, String> {
    text = try (fs.read_text("enums.choices") |> Result.map_err(fn e -> "enums.choices: ${e}"))

    enums =
        String.split(text, "\n")
        |> Iter.with_index()
        |> Iter.filter(fn #(_, line) -> String.trim(line) != "")
        |> Iter.map(fn #(i, line) -> enum_of(i + 1, line))
        |> Result.collect()

    source = "// Generated by `nomi tool choices generate` from enums.choices. Do not edit.\n" + String.join(
        try enums,
        "\n",
    )

    try (fs.write_text("enums.nomi", source) |> Result.map_err(fn e -> "enums.nomi: ${e}"))
    io.print("wrote enums.nomi")
    Ok(Unit)
}

// The enum line `number` declares.
fn enum_of(number: Int, line: String) -> Result<String, String> {
    #(name, words) = case String.split(line, ":") |> Iter.to_list() {
        [name, words] -> #(String.trim(name), String.words(words))
        _ -> return Err("enums.choices:${number}: write `Name: first second third`")
    }

    case Iter.find(words, fn w -> !snake_case?(w)) {
        Some(w) ->
            return Err("enums.choices:${number}: `${w}` is not a snake_case word")

        None -> {}
    }

    variants = words |> Iter.map(fn w -> "    ${pascal(w)}\n") |> String.join()
    Ok("/// The choices of `${name}` in enums.choices.\npub enum ${name} {\n${variants}}\n")
}

fn snake_case?(word: String) -> Bool {
    word != "" and Iter.all?(word, fn c -> String.contains?("abcdefghijklmnopqrstuvwxyz_", c))
}

// `extra_large` as `ExtraLarge`.
fn pascal(word: String) -> String {
    String.split(word, "_")
    |> Iter.map(fn w -> {
        String.to_upper(String.slice(w, 0, 1)) + String.slice(w, 1, String.length(w))
    })
    |> String.join()
}

// FILE: generators/choices/nomi.toml
[module]
name = "choices"
entry_points = ["tools/generate"]

// FILE: generators/choices/go.mod
module choices

go 1.27.0

// FILE: go.mod
module cafe

go 1.27.0

require choices v0.0.0

replace choices => ./generators/choices

// FILE: nomi.toml
[module]
name = "cafe"
entry_points = ["main"]
```

True

`enums.nomi` starts with a comment saying it is generated and must not be
edited by hand: the next run of the tool would undo the edit. Change
`enums.choices` and run the tool instead.

The tool is the place to check its input. A word that cannot name a variant
stops it with an error that names the line, and it writes nothing:

## Keeping generated files current

Generated files go stale when their inputs change and nobody runs the
tool. A careful generator gives you two ways to notice, which this second
example adds. It turns each CSV file under `data/` into a lookup function:
the header names the key and the value with their types, and each row maps
a key to a value.

```csv
code: String,basis_points: Int
usd,9200
gbp,11700
jpy,61
```

The generated `tables.nomi` holds a function `rates(code: String) ->
Maybe<Int>` with one `case` arm per row. A cell is written into the code as
it is, so a rate of `92.00` would be a type error in the generated code,
which `nomi check` reports.

The first way is the header. The tool records a SHA-256 digest of its
inputs (`hash.sha256_hex` from [std/hash](/reference/hash/)) in the header
of each file it writes:

```nomi
// Generated by `nomi tool csvdata generate` from data/*.csv. Do not edit.
// inputs sha256: e9e14b41a5e6e5c0e3b42572f14e9f3dd4e1a0e492a3e594a046584d55136330
```

With `--check`, the tool writes nothing and fails when a file is not what
it would write. That is the command to run in an automated check:

```console
$ nomi tool csvdata generate --check
error: tables.nomi, tables_test.nomi would change: run `nomi tool csvdata generate`
```

The second way is a test. The tool writes `tables_test.nomi`, whose test
computes the digest of the inputs again and compares it with the one the
header records, so a plain `nomi test` fails when a CSV file changed since
the tool last ran. A test resolves a relative path under its module root,
so it reads the same files wherever `nomi test` runs:

```nomi
// Generated by `nomi tool csvdata generate` from data/*.csv. Do not edit.
// inputs sha256: e9e14b41a5e6e5c0e3b42572f14e9f3dd4e1a0e492a3e594a046584d55136330
import csvdata

test "generated tables are current" {
    assert csvdata.inputs_digest("data")
        == Ok("e9e14b41a5e6e5c0e3b42572f14e9f3dd4e1a0e492a3e594a046584d55136330")
}
```

The digest is `csvdata.inputs_digest`, a function of the module, so the
tool and the test compute it the same way. Edit a rate in `data/rates.csv`
and run this example, which runs the tool and then the test: the tool
rewrites `tables.nomi` and `tables_test.nomi`, and the test passes again.
Run it once more and the tool finds both files up to date.

```nomi-run manual tool:csvdata/generate
// FILE: data/rates.csv
code: String,basis_points: Int
usd,9200
gbp,11700
jpy,61

// FILE: data/names.csv
code: String,name: String
usd,US dollar
gbp,Pound "sterling"
jpy,Yen ${not interpolated}

// FILE: tables_test.nomi
// Generated by `nomi tool csvdata generate` from data/*.csv. Do not edit.
// inputs sha256: e9e14b41a5e6e5c0e3b42572f14e9f3dd4e1a0e492a3e594a046584d55136330
import csvdata

test "generated tables are current" {
    assert csvdata.inputs_digest("data")
        == Ok("e9e14b41a5e6e5c0e3b42572f14e9f3dd4e1a0e492a3e594a046584d55136330")
}

// FILE: tables.nomi
// Generated by `nomi tool csvdata generate` from data/*.csv. Do not edit.
// inputs sha256: e9e14b41a5e6e5c0e3b42572f14e9f3dd4e1a0e492a3e594a046584d55136330
/// The `name` of each `code` in data/names.csv.
pub fn names(code: String) -> Maybe<String> {
    case code {
        "usd" -> Some("US dollar")
        "gbp" -> Some("Pound \"sterling\"")
        "jpy" -> Some("Yen \${not interpolated}")
        _ -> None
    }
}

/// The `basis_points` of each `code` in data/rates.csv.
pub fn rates(code: String) -> Maybe<Int> {
    case code {
        "usd" -> Some(9200)
        "gbp" -> Some(11700)
        "jpy" -> Some(61)
        _ -> None
    }
}

// FILE: generators/csvdata/csvdata.nomi
//# Lookup tables from CSV files. `nomi tool csvdata generate` writes
//# tables.nomi from the module's data/*.csv files, a function per file,
//# and tables_test.nomi, whose test calls `inputs_digest` to see that the
//# files have not changed since.

import {
    std/fs
    std/hash
}

/// The SHA-256 digest of the CSV files directly in `dir`, each path and
/// text in name order: what tables.nomi's header records.
pub fn inputs_digest(dir: String) -> Result<String, String> {
    paths = try (fs.glob("${dir}/*.csv") |> Result.map_err(fn e -> "${dir}: ${e}"))

    texts =
        paths
        |> Iter.sort()
        |> Iter.map(fn path -> {
            fs.read_text(path)
            |> Result.map(fn text -> "${path}\u{0}${text}\u{0}")
            |> Result.map_err(fn e -> "${path}: ${e}")
        })
        |> Result.collect()

    Ok(hash.sha256_hex(String.to_bytes(String.join(try texts))))
}

// FILE: generators/csvdata/tools/generate.nomi
// `nomi tool csvdata generate [--check]`: write tables.nomi from data/*.csv,
// a lookup function per file, and tables_test.nomi, a test that the files
// have not changed since. A file's header names the key and the value with
// their types, `code: String,basis_points: Int`; every other line is a key,
// a comma and a value. With `--check` it writes nothing and fails when a
// file is not what it would write.
import {
    std/fs
    std/io
    csvdata
}

struct App {
    args: List<String>
}

fn boot(startup: Startup) -> Result<App, String> {
    Ok(#App{args: startup.args})
}

fn main() -> Result<Unit, String> {
    check = case App.args {
        [] -> False
        ["--check"] -> True
        _ -> return Err("usage: nomi tool csvdata generate [--check]")
    }

    paths = try (fs.glob("data/*.csv") |> Result.map_err(fn e -> "data: ${e}"))
    tables = try (paths |> Iter.sort() |> Iter.map(table) |> Result.collect())
    digest = try csvdata.inputs_digest("data")

    header = "// Generated by `nomi tool csvdata generate` from data/*.csv. Do not edit.\n// inputs sha256: ${digest}\n"

    test_file = header + "import csvdata\n\ntest \"generated tables are current\" {\n    assert csvdata.inputs_digest(\"data\")\n        == Ok(\"${digest}\")\n}\n"

    files = [#("tables.nomi", header + String.join(tables, "\n")), #("tables_test.nomi", test_file)]

    stale =
        files
        |> Iter.filter(fn #(path, text) -> fs.read_text(path) != Ok(text))
        |> Iter.map(fn #(path, _) -> path)
        |> Iter.to_list()

    if Iter.empty?(stale) {
        io.print("up to date")
    } else if check {
        return Err("${String.join(stale, ", ")} would change: run `nomi tool csvdata generate`")
    } else {
        written =
            files
            |> Iter.filter(fn #(path, _) -> Iter.contains?(stale, path))
            |> Iter.map(fn #(path, text) -> {
                fs.write_text(path, text) |> Result.map_err(fn e -> "${path}: ${e}")
            })
            |> Result.collect()

        _ = try written

        io.print("wrote ${String.join(stale, ", ")}")
    }

    Ok(Unit)
}

// The lookup function of the CSV file at path.
fn table(path: String) -> Result<String, String> {
    text = try (fs.read_text(path) |> Result.map_err(fn e -> "${path}: ${e}"))
    lines = String.lines(text) |> Iter.filter(fn l -> l != "") |> Iter.to_list()

    #(key, value, rows) = case lines {
        [first, ..rows] ->
            case String.split(first, ",") |> Iter.map(field) |> Iter.to_list() {
                [Some(k), Some(v)] -> #(k, v, rows)
                _ -> return Err("${path}:1: the header is `key: Type,value: Type`")
            }

        [] ->
            return Err("${path}: the file is empty; its first line is `key: Type,value: Type`")
    }

    #(key_name, key_type) = key
    #(value_name, value_type) = value

    name =
        String.split(path, "/")
        |> Iter.last()
        |> Maybe.with_default(path)
        |> String.replace(".csv", "")

    arms =
        rows
        |> Iter.with_index()
        |> Iter.map(fn #(i, row) -> {
            case String.split(row, ",") |> Iter.to_list() {
                [k, first, ..more] -> {
                    v = String.join([first, ..more], ",")
                    Ok("        ${cell(k, key_type)} -> Some(${cell(v, value_type)})\n")
                }

                _ ->
                    Err("${path}:${i + 2}: a row is a key, a comma and a value")
            }
        })
        |> Result.collect()

    Ok(
        "/// The `${value_name}` of each `${key_name}` in ${path}.\npub fn ${name}(${key_name}: ${key_type}) -> Maybe<${value_type}> {\n    case ${key_name} {\n${String.join(
            try arms
        )}        _ -> None\n    }\n}\n"
    )
}

// A header cell `name: Type`, as the name and the type.
fn field(cell: String) -> Maybe<#(String, String)> {
    case String.split(cell, ":") |> Iter.map(String.trim) |> Iter.to_list() {
        [name, type_name] when name != "" and type_name != "" -> Some(#(name, type_name))
        _ -> None
    }
}

// A cell as Nomi source: a string literal for a String, else the cell as it
// is, which the checker then checks against the type.
fn cell(text: String, type_name: String) -> String {
    if type_name == "String" {
        String.to_literal(text)
    } else {
        String.trim(text)
    }
}

// FILE: generators/csvdata/nomi.toml
[module]
name = "csvdata"
entry_points = ["tools/generate"]

// FILE: generators/csvdata/go.mod

// FILE: go.mod
module rates

go 1.27.0

require csvdata v0.0.0

replace csvdata => ./generators/csvdata

// FILE: nomi.toml
[module]
name = "rates"
entry_points = ["main"]
```

## Where to go next

sqlkit's `generate` is a whole generator built this way: it reads SQL
migrations and query files, asks SQLite to describe each query, and writes
the schema's row types and a typed function per query, with a SHA-256 of
its inputs in each header, `--check`, and a generated test. The
[Databases](/databases/#checked-sql-with-sqlkit) chapter walks through it.
