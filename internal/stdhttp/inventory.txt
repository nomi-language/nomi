# Every exported identifier of Go's HTTP packages, and what Nomi does with
# it (internal/stdhttp's package doc). TestGoInventoryIsComplete holds this
# file to the Go the test runs under.
#
# "@ <package>" starts a package's rows. A row is
#   <name or group> | covered | phase <n> | <the Nomi name, then notes>
#   <name or group> | mapped  | phase <n> | <how Nomi does the same job>
#   <name or group> | skipped | <why Nomi does not offer it>
# A name is "Name" or "Type.Name"; one "*" makes a group, which matches
# only names with as many dots. An exact row wins over a group, a longer
# group over a shorter one. A covered row of a phase that has landed
# (LandedPhase) names, in its first backticks, a declaration std holds.
