# Exercism exercises

Exercism exercises solved in Nomi, one directory each: the solution, a test
file with every case from the exercise's canonical data, and `NOTES.md` with
the judgement calls made and the friction met while writing it. Each line
below gives the exercise's status: `clean` (nothing to report), `friction`
(something was clumsy or missing) or `bug` (a compiler or runtime bug, with a
reproducer in the notes).

The problem descriptions and canonical test data come from Exercism's
[problem-specifications](https://github.com/exercism/problem-specifications)
repository, under the MIT licence, Copyright (c) 2014, 2019, 2021 Exercism.
