# Exercism ports

Exercises from Exercism's problem-specifications, solved in idiomatic Nomi.
Each directory holds a solution, a test file with every current canonical
case, and `NOTES.md`, which records the judgement calls in the solution and
the friction met while writing it. The problems and their canonical data are
adapted from https://github.com/exercism/problem-specifications, which is
MIT-licensed (Copyright (c) 2014, 2019, 2021 Exercism).
