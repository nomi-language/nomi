# Hello World

Subject: Strings & Text

Answer the greeting "Hello, World!".

Adapted from Exercism problem-specifications (MIT), exercises/hello-world.

## Choices

- `hello` is a function returning the `String`, as the canonical `hello` property is, rather than a `main` that prints it. A value can be asserted; printed output would need `io.replay` to check.
- The string literal is the whole body: a function's last expression is its result.

## Friction

None.
